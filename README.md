# Penilai Laporan Ilmiah & KTI

Aplikasi penilaian laporan ilmiah dan karya tulis ilmiah (KTI) yang gratis, ringan, dan dapat dijalankan langsung di browser.

## Fitur
- Form identitas karya dan penilai
- Rubrik penilaian 5 aspek
- Skor 1-4 per komponen
- Perhitungan otomatis dan predikat
- Bisa dicetak / di-save sebagai PDF
- Tidak memerlukan backend atau database

## Cara pakai
1. Buka file `index.html` di browser.
2. Isi data karya dan penilai.
3. Pilih skor untuk setiap aspek.
4. Klik `Hitung Nilai`.
5. Cetak atau simpan sebagai PDF bila diperlukan.

## Deploy ke Netlify
1. Upload repo ini ke GitHub.
2. Masuk ke Netlify.
3. Pilih `Add new site` > `Import an existing project`.
4. Hubungkan ke GitHub dan pilih repositori ini.
5. Biarkan build command kosong.
6. Publish directory: `.` atau root project.
7. Deploy.

Aplikasi ini dapat langsung berjalan sebagai situs statis tanpa build process.
